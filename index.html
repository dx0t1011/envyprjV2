Personal use tool

envyprjV2

Личный инструмент для публикации видео на собственный канал YouTube через официальный YouTube Data API v3. Приложение не является публичным сервисом: оно запускается локально, авторизуется под одним аккаунтом Google и работает только с каналом своего владельца.

  • Загрузка видеофайлов на канал владельца аккаунта
  • Установка названия, описания, тегов и обложки
  • Смена статуса приватности (черновик → публикация)
  • Локальное хранение токена доступа на компьютере владельца

Приложение использует сервисы YouTube API и подчиняется Условиям использования YouTube API Services. Политика конфиденциальности Google — policies.google.com/privacy.
