Политика конфиденциальности

Приложение: envyprjV2 · Дата вступления в силу: 19 ноября 2026 г.

envyprjV2 — персональный инструмент, который запускается локально на компьютере владельца и используется для загрузки видео на собственный канал YouTube. У приложения нет серверной части, базы пользователей и регистрации: единственный пользователь — владелец аккаунта, который его запускает.

Какие данные обрабатываются

  • Учётные данные Google OAuth — токен доступа (access token и refresh token), который выдаётся после того, как владелец аккаунта явно разрешает приложению доступ. Токен хранится локально на компьютере владельца в файле ~/.config/envyprjV2/token.json с правами доступа только для владельца.
  • Видеофайлы и метаданные, которые владелец сам выбирает для загрузки (название, описание, теги, файл обложки). Они передаются напрямую в YouTube Data API v3 и нигде больше не сохраняются.
  • Технические журналы — вывод консоли на компьютере владельца. Никуда не отправляются и не собираются централизованно.

Какие данные НЕ собираются

  • Приложение не собирает персональные данные третьих лиц.
  • Не использует cookies, аналитику, трекеры или рекламу.
  • Не передаёт и не продаёт данные третьим лицам.
  • Не хранит пароли Google — авторизация проходит на стороне Google.

Запрашиваемые разрешения и зачем они нужны

  • https://www.googleapis.com/auth/youtube.upload — загрузка видео и установка обложки на канал владельца аккаунта.
  • https://www.googleapis.com/auth/youtube.readonly — чтение информации о собственном канале и статусах загруженных видео, чтобы показывать результат загрузки.

Удаление данных

Владелец может в любой момент отозвать доступ приложения к аккаунту Google на странице myaccount.google.com/permissions и удалить локальный файл с токеном. После отзыва доступ приложения прекращается немедленно, а сохранённый токен перестаёт действовать.

Сторонние сервисы

Приложение использует YouTube API Services. Используя его, вы также принимаете Условия использования YouTube API Services. Политика конфиденциальности Google доступна на policies.google.com/privacy.

Privacy Policy (English summary)

envyprjV2 is a personal, locally-run tool that uploads videos to the owner's own YouTube channel using YouTube API Services. It has no backend service and no user database.

The only stored credential is the Google OAuth token, kept locally on the owner's machine. Videos and metadata the owner selects are sent directly to the YouTube Data API v3 and are not retained anywhere else. The app requests youtube.upload (upload videos and set thumbnails) and youtube.readonly (read the owner's own channel and video status). No analytics, cookies, trackers, advertising, or third-party data sharing.

Access can be revoked at any time at myaccount.google.com/permissions. Contact: envyproject@gmail.com.
