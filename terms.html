envyprjV2 — персональное программное обеспечение, предоставляемое «как есть» (as is), без каких-либо гарантий. Приложение не является коммерческим сервисом и не предназначено для использования третьими лицами.

Назначение

Приложение используется владельцем аккаунта Google для загрузки собственных видеоматериалов на собственный канал YouTube и управления метаданными этих материалов.

Ответственность владельца

  • Владелец самостоятельно отвечает за содержание загружаемых видео.
  • Владелец обязуется соблюдать Условия использования YouTube и Условия использования YouTube API Services.
  • Владелец не использует приложение для массовых, автоматических или чужих загрузок, а также для распространения контента, нарушающего права третьих лиц.

Ограничение ответственности

Автор приложения не несёт ответственности за любые последствия использования, включая блокировки аккаунта, потерю данных или нарушение квот YouTube API. Приложение не хранит резервные копии загружаемых файлов.
